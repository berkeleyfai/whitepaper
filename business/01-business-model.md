# 商业模式 Business Model

## 收入三大类

```
┌──────────────────────────────────────────────────────────────┐
│                                                              │
│  ┌──────────────┐   ┌──────────────┐   ┌──────────────┐      │
│  │ 1. 房产收入   │   │ 2. 孵化收入   │   │ 3. 生态收入   │      │
│  │  （稳定）     │   │  （高弹性）    │   │  （网络效应）  │     │
│  └──────────────┘   └──────────────┘   └──────────────┘      │
│         │                  │                   │             │
│         └──────────────────┼───────────────────┘             │
│                            ↓                                 │
│                     共同进入 Value Pool                        │
│                                                              │
└──────────────────────────────────────────────────────────────┘
```

### 1. 房产运营收入（稳定底座）

- **租金**：伯克利核心地段学生公寓
- **资产估值更新**：根据第三方估值定期重估，影响信息披露与生态信号

### 2. AI 孵化器收入（高成长）

- **服务费**：项目筛选、技术支持、产业对接、合规咨询等
- **退出分成 / 股权收益**：与孵化项目签订深度合作协议
- **专利与技术授权**：通过 AI Brain Lab 联合研发产生的 IP 授权
- **服务与管理费**：针对深度合作项目

### 3. 生态与代币收入（网络效应）

- **平台服务费**：高级数据分析、定制对接、专业资源协调等
- **特定交易费**：链上特定模块或服务调用产生的费用

---

## 价值流向（Value Waterfall）

所有营收先扣除直接成本（物业管理、税费、保险、维护、合规等），剩余进入 **Value Pool**，按以下顺序分配：

| 优先级 | 用途 | 治理要求 |
|--------|------|---------|
| 1️⃣ | 资产运营、审计、法律、税务、风险准备金 | 自动 |
| 2️⃣ | AI 孵化器、算力基础设施、实验室 R&D、市场扩张 | 自动 |
| 3️⃣ | 二级市场回购、生态激励、Treasury 储备、新 RWA 资产收购 | **需治理批准 + 合规审查** |

> ⚠️ 注意：白皮书原文明确写："Repurchase and treasury management actions, if any, are designed to support long-term ecosystem health rather than to constitute commitments to token price, liquidity, or returns." 即**回购销毁不是承诺**。

## 经济飞轮设想

```
  RWA 资产稳定 → 吸引初期资金 → 投入 AI 孵化与基础设施合作
        ↑                                  ↓
        |                          孵化成果与产业合作
   生态扩张                                  ↓
        |                          生态影响力增强
        ↑                                  ↓
   收购更多优质资产 ← 更多资金、创业者、伙伴进入 ← BAI 使用需求增加
```

这个飞轮**理论上**成立，但加速度的关键节点：

1. 第一批孵化项目能否在 12 个月内拿到后续融资（验证 signal 效应）
2. 第二批 RWA 资产能否在 24 个月内收购上链（验证可复制性）
3. 回购机制能否在 18 个月内首次触发（验证 Treasury 健康度）
