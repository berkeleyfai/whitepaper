# 技术架构 Technical Architecture

## 多链策略

```
┌──────────────────────┐                ┌──────────────────────┐
│  Solana（主链）       │                │  Ethereum（结算/锚定）│
│                      │   跨链桥        │                      │
│  • 高频生态交互        │ ←────────────→ │  • 资产记录锚定        │
│  • 治理投票           │   Wormhole/    │  • 与 DeFi/机构生态对接 │
│  • 日常激励分发        │   LayerZero    │  • Layer 2 扩展        │
│  • 低成本访问           │                │  • 大额结算            │
│                      │                │                      │
└──────────────────────┘                └──────────────────────┘
```

### 选 Solana 的理由

- **高 TPS + 低费用**：日常治理与激励发放可承受
- **亚秒级确认**：用户体验流畅
- **生态成熟**：DEX（Raydium、Jupiter）、NFT、基础设施完善

### 选 Ethereum 的理由

- **顶级安全性与去中心化**：核心资产价值的锚定层
- **机构认可度**：CEX/DEX、借贷、托管接入广泛
- **成熟 L2 生态**：Arbitrum、Optimism 解决拥堵成本问题

### ⚠️ 跨链桥风险提示

白皮书提到使用 **Wormhole 或 LayerZero** 实现跨链：

- **Wormhole 历史上发生过 3.2 亿美元漏洞攻击**（2022）
- 跨链桥是 DeFi 历史上**最大的攻击面**
- 严肃 RWA 项目需要：(1) 限额机制 (2) 时间锁 (3) 紧急暂停权限 (4) 保险池

> 项目方应明确：是否考虑放弃多链改为单链，或者做更严格的跨链风险控制。

## 智能合约系统

### Asset Mapping Contract（RWA Protocol）

链下法律框架与链上记录的核心连接器。

**功能**：

- 定义生态权限、披露记录、合规交互的映射关系
- 集成 KYC/AML 验证白名单地址
- 仅合规地址有权访问受限功能
- 强制转账与访问限制（如锁仓期、合格参与者限额）

### Smart Contract Allocation System

自动化执行：

- Value Pool 预算编排
- Treasury 分配
- 回购执行记录
- 治理结果上链

> 注意：**不实施**针对市场化运营的固定收益分配逻辑（这是 utility token 与 security token 的关键差异）。

## 数据透明与预言机

### Chainlink Proof of Reserves (PoR)

定期自动验证 RWA 资产的链下储备价值，数据上链。

```
托管人/审计师 → 链下储备数据 → Chainlink 节点 → 链上记录
                                    ↓
                            智能合约可读
                                    ↓
                            前端实时展示
```

### 预言机网络

关键财务指标（如净收入）由**多个独立预言机节点共同签名**后才能上链，防止单点故障与数据篡改。
