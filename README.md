# Welcome to BerkeleyFuture AI

> **一句话**：把伯克利学生公寓的现金流代币化，作为底座运营一个聚焦 AI Agent 与具身智能的孵化器。

BerkeleyFuture AI（**BAI**）尝试把三个东西拧在一起：

1. **真实世界资产（RWA）** —— 伯克利大学城周边的学生公寓
2. **AI 加速器** —— 选址硅谷，聚焦 AI Agent 与具身智能
3. **代币经济** —— BAI Token 作为生态访问凭证与治理工具
