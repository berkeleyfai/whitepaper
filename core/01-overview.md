# 项目概览 Overview

## 项目是什么

BerkeleyFuture AI（BAI）是一个 **RWA + AI 孵化器** 复合型项目。

它有两条腿：

```
┌──────────────────────────────┐    ┌──────────────────────────────┐
│   腿 1：稳定现金流底座           │    │   腿 2：高成长上层             │
│                              │    │                              │
│   伯克利学生公寓                │    │   硅谷 AI Agent /            │
│   ↓ 租金 + 估值更新             │    │   具身智能孵化器                │
│   SPV 持有 → 链上锚定信息          │ +  │   ↓ 服务费 + 退出分成          │
│                              │    │                              │
│   特点：现金流可预测、波动低           │    │   特点：高弹性、高风险             │
└──────────────────────────────┘    └──────────────────────────────┘
                  ↓                              ↓
                  └──────────────┬───────────────┘
                                 ↓
                          BAI 生态价值池
                  （回购、Treasury、生态激励）
```

---

## 与其他 RWA 项目的差异

大多数 RWA 项目只做一件事：把某种资产（私募信贷、美债、房产）代币化，给持有人提供收益。

BAI 想做的不一样 —— 它把 RWA 当作**冷启动燃料**和**信任锚**，真正的成长引擎是上面的 AI 孵化器。

| 维度 | 主流 RWA 项目（如 Ondo、Maple） | BAI 的尝试 |
|------|------------------------|-----------|
| 底层资产 | 美债、私募信贷 | 学生公寓房产 |
| 收益形式 | 直接派息 / 收益型代币 | 不直接派息，通过回购销毁与生态扩张间接传导 |
| 收益波动 | 低 | 高（取决于孵化项目表现） |
| 主要叙事 | 金融效率、利率传导 | AI 创业生态 + 真实资产支撑 |

---

## 双引擎模型的逻辑

BAI 押的是这样一个判断：

1. **纯 AI 加速器** 的代币没有底层支撑，市场难以持续给估值
2. **纯 RWA 房产代币** 增长曲线平缓，难以激发加密用户兴趣
3. **两者结合** 才能既有故事性又有真实业务

这个组合的关键挑战在于：

- 房产是慢的，AI 是快的，**节奏怎么对齐？**
- 房产需要保守合规叙事，AI 需要激进增长叙事，**对外讲故事时如何避免分裂？**
- 两边的现金流都进同一个 Treasury，**如何平衡分配？**

商业模式与 Tokenomics 章节会展开这些问题的设计回应。
